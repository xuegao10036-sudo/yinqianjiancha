# 印前检查-雪糕

当前版本 **v11.68** · 完整变更日志见 [更新日志.txt](更新日志.txt) · 许可 [MIT](LICENSE)

在 Illustrator 里做印前自检的面板扩展：八张检查卡覆盖出血 / 隐藏内容 / 字体 / 图片 / 油墨与描边 / 叠印 / 清理 / 色板，  
卡上直接给动作按钮 —— 一键转曲、一键嵌入、一键清除叠印、删除全部隐藏对象、删除未使用的色板，  
逐卡触发、各自确认。扫描与写操作全部在 Illustrator 内部完成，不需要另装运行时。

---

## 功能（八张检查卡）

八张卡**默认全部检查**（唯 ⑧ 色板卡出厂关闭）；在「设置」里关掉的卡**整卡不再渲染**（不是灰化占位）。  
下表编号是**默认显示顺序**，只为便于指代 —— 在设置里拖拽换位后，卡片本身不变，只是上下位置变了。

### 徽标怎么读

| 项目 | 规则 |
| -- | -- |
| 颜色 | 绿 = 正常，黄 = 注意，红 = 问题；**卡片左边框与徽标同色**（同一档严重度，不会出现"边框黄、徽标红"） |
| 卡头 | 最多 **两颗**：主 = 最严重的一档；次 = **同一优先级里下一个能下手处理的** |
| 句式 | 一律「名词 + 数字 + 量词」：`隐藏 4 个` / `可清理 5 个` / `偏重 2 处` / `缺字体 2 个` / `小字号 3 处` |
| 正常态 | 一律「无X」：`无隐藏` / `无异常` / `无叠印` / `无需清理` / `无未使用` / `无图片` |

次徽标只在「主徽标正好是最严重那一位」时才会出现，所以正常态、单问题态**永远只有一颗**。  
量词分工：数**图形 / 对象**用「个」，按**落点数**用「处」（文本溢出、字号线、叠印）。  
一个例外：卡③ 字体的主徽标本身是**三段拼接串**（未转曲 + 缺字体 + 小字号），不分主次。

| 卡片 | 检查内容 | 卡头徽标（主 / 次） |
| -- | -- | -- |
| ① 画板 · 出血 · 色彩 | 画板尺寸、逐画板实测出血、色彩模式 | `CMYK` / `RGB`；并列 `出血不足`（不带数字） |
| ② 隐藏 | 隐藏图层与隐藏对象 | `隐藏 N 个` / `无隐藏` |
| ③ 字体 | 未转曲文本框、字体清单、缺失字体、极小字号、文本溢出 | 三段拼接：`未转曲 N 个` 或 `已转曲` + `缺字体 N 个` + `小字号 N 处` |
| ④ 图片 | 嵌入 / 链接 / 缺失、低于 300ppi | `缺失 N 张` / `偏低 N 张` / `未完成` / `有链接图` / `全部嵌入` / `无图片`；次徽标取同一优先级的下一位 |
| ⑤ 油墨 · 描边 | 油墨总量、色版过浅、描边宽度 | `超标 N 处` / `偏重 N 处` / `无异常`；次 `描边细 N 处` / `色版浅 N 处` |
| ⑥ 叠印（两版可切） | 处于叠印状态的对象（文字与图形） | 全清理 `叠印 N · 白叠印 N` / `叠印 N` / `未完成` / `无叠印`；分级版 `需处理 N · 正常 N` / `未完成` / `无叠印` |
| ⑦ 清理 | 游离点、未上色对象、空文本路径 | `可清理 N 个` / `未检查` / `无需清理` |
| ⑧ 色板 | 未被任何对象引用的色板 / 渐变 / 图案 | `未使用 N 个` / `未检查` / `无未使用` / `统计失败` |

每颗徽标**各报各的数，不互相累加**：`缺字体 2 个` 是"2 种字体缺失"，`小字号 3 处` 是"3 个落点"，  
与 `未转曲 N 个`（N 个文本框）不是同一个量 —— 三个数加起来没有意义。

**卡头定位**：字体 / 叠印 / 清理 三张卡的卡头徽标右侧有一个准星按钮（**该卡有命中时才出现**），点一下  
就会**选中这张卡的全部问题对象**并刷新视图 —— 不用再对着样本清单猜是哪个。  
⑤ 油墨卡因为是分块报的，按钮放在**每个块标题后面**（4 块各一颗），点哪颗就只选那一块的对象。  
④ 图片卡没有卡头按钮，它的两颗在**两个段标题后面**（嵌入段 / 分辨率段各一颗）。  
它**只选中、不改状态**：锁定或隐藏的对象不会被解锁、不会被显形，只在顶部提示条里报  
「M 个锁定 / K 个隐藏未选（图层「xx」）」，要不要动它们由你决定。

**数量上限**：清单类最多列 5 条，超出时在标题行右端提示「仅列出前 5 处 / 5 张 / 5 个」；  
扫描配额为 3000 个对象，隐藏文字另按 500 帧封顶。两者是两件事 —— 前者管「显示几条」，后者管「扫多少个」；  
**命中配额意味着后面的对象没被检查**，卡片会明说「未完成 / 可能不止 N」，请留意。

### 卡 ① 画板 · 出血 · 色彩

| 项目 | 说明 |
| -- | -- |
| 画板清单 | 逐个画板列出名称与尺寸（`宽 × 高 mm`），当前画板标「(当前)」 |
| 出血 | **逐画板实测**四条边（对象到画板边的实际距离，容差 0.05mm）；不足 3mm 的画板会被列出，并标明**具体是哪条边**不足，如「上 0mm、下 0mm、右 2.9mm」 |
| 色彩模式 | 常驻一行。CMYK 显示白字；RGB 显示红字并提示「请转 CMYK（文件 → 文档颜色模式）」 |

未贴到边的方向按 0mm 计，空画板四边都按 0mm 报；全部达标时显示「出血全部 ≥ 3mm，达标。」  
出血不足时，除主徽标外**并列**一个黄徽标「出血不足」—— **有意不带数字**（不足几处看卡内逐画板清单）。

### 卡 ② 隐藏

| 项目 | 说明 |
| -- | -- |
| 统计 | 分别统计**隐藏图层**与**隐藏对象**，汇总为一行「隐藏图层 N 个 · 隐藏对象 N 个」 |
| 清单 | 列出隐藏图层的名称（最多前 5 个）；没有隐藏内容时正文显示「无 隐藏图层、隐藏对象。」 |
| 徽标 | `隐藏 N 个`（红）/ `无隐藏`（绿）——「无隐藏」只看卡头，正文仍写「无 隐藏图层、隐藏对象。」 |
| 删除 | 卡片底部「删除全部隐藏对象」按钮。**只在可见图层内确实藏着对象时出现** —— 隐藏图层的对象不在删除范围，若隐藏内容全在隐藏图层里，按钮不会出现 |

**卡片左边框与徽标同色**。v11.66 之前边框是黄的、徽标是红的，两处不同档，看着像"黄卡里有个红点"。

### 卡 ③ 字体

| 项目 | 说明 |
| -- | -- |
| 未转曲文本框 | 列出总数与文档中用到的字体名（最多 8 种，超出折叠为「…等 N 种」；名字过长会单行截断，悬停可看全名） |
| 缺失字体 | 命中时列出具体字体名，并追加一个红徽标 `缺字体 N 个`；判据见下 |
| 极小字号 | `小于 6pt 的文本 N 处` 并列出样本（`文字 — N pt`）；计数与徽标 `小字号 N 处` 一律标红 |
| 文本溢出 | 溢出文本框的片段与文本类型（区域 / 路径 / 点），下方提示「转曲也找不回来」 |
| 隐藏文字 | 树遍历只扫可见对象，隐藏文字单独统计，提示「另有 N 个隐藏文字未转曲，勾选「显示全部」可一并转曲。」（配额：前 500 帧） |

> **看徽标别误解**：卡③ 的主徽标 `未转曲 N 个` 是**可见 + 隐藏文字合并计数** —— 只看徽标会以为隐藏文字也转了曲，以卡内那行提示为准。

> **「文本溢出」有意不占卡头徽标**：卡头三颗徽标加定位按钮实测已占 253.9px（可用宽 300px），  
> 再加第四颗连徽标本身都放不下。而溢出的一定是文本框 ⇒ 必然同时命中「未转曲」，卡头照样标红，不会漏看。

**缺失字体的判定**同时用三条判据：

1. 不在系统字体表中；
2. 系统字体表里是**占位条目**（无 style 且 family 为空或等于字体名）；
3. **切分痕迹** —— 条目的 family / style 恰好是字体名在**首个连字符**处硬切出来的  
   （style = 连字符后段，family = 前段 + 空格 + 后段）。这条是为「名字自带连字符的缺失字体」补的：  
   这类字体旧版会整类漏报。

#### 一键转曲（两个选项）

有未转曲文本框（或隐藏文字）时，卡片底部会出现「一键转曲」按钮，配两个勾选项：

- **显示全部**：转曲前显示隐藏图层，并取消对象级隐藏（Ctrl+3）
- **解锁全部**：转曲前解锁图层，并解除对象级锁定（Ctrl+2）与锁定组

| 勾选组合 | 效果 |
| -- | -- |
| 两项都勾 | 解除全部隐藏与锁定，转曲文档中所有文字 |
| 只勾解锁 | 转曲其中可见的文字；仍隐藏的文字跳过 |
| 只勾显示 | 转曲其中未锁定的文字 |
| 都不勾 | 只转曲本就可见且未锁定的文字，不改动任何状态 |

> 转曲**会下钻到符号（Symbol）内部**：符号实例里未转曲的文字会被转掉（v10.46 起）。隐藏的符号实例整收不动。

### 卡 ④ 图片

一张卡管两件事：**图片怎么进来的**（嵌入 / 链接 / 缺失）和**够不够清晰**（低于 300ppi）。  
结构从上到下：嵌入计数 → 链接文件名清单 → 分辨率计数 → ppi 清单 → 「一键嵌入」按钮（固定卡末）。

| 项目 | 说明 |
| -- | -- |
| 嵌入段 | `嵌入 N 张 · 链接 N 张 · 缺失 N 张`，下面列链接图的文件名（最长 40 字符，悬停看**完整路径**）；源文件不存在的会标记「⚠ 源文件不存在」 |
| 分辨率段 | `分辨率 <300ppi N 张 · 达标 N 张`；有图读不出 ppi 时再拼 `· 无法判定 N 张`。下面列文件名 + 实际 ppi，最多 5 张 |
| 一键嵌入 | 有链接图时出现；确认框标题「确认嵌入」，写明链接图总数（含隐藏对象） |

**徽标的优先级**：缺失(红) > 偏低(黄) > 未完成(黄) > 有链接图(黄) > 全部嵌入(绿) > 无图片(绿)。  
主徽标取最严重一档，次徽标取**同一优先级里下一位**（`缺失 N 张` 之后可能是 `偏低 N 张` 或 `未完成`）。

> **「有链接图」不进次徽标**：文档里有链接图是常态，不是待处理的问题，嵌入段那行已经用黄字标出来了，  
> 再挂到卡头只是噪音。所以「有链接图」这一档永远不会出现第二颗。

> **口径提醒**：检查卡与清单**只统计可见对象**；而「一键嵌入」是**文档级操作**，  
> 处理的是文档中**全部**链接图（含隐藏对象），确认框会写明总数。
>
> **嵌入口径（v9.9 起）**：**不再栅格化** —— PDF / AI / EPS 等矢量链接与位图一样走 Illustrator  
> 原生「嵌入」，效果与在 AI 里手动嵌入一致；具体结果（是否保留图层、能否编辑）跟随你上次  
> 嵌入时用的导入选项。操作不可撤销，建议先存盘。

**分辨率判定**：ppi 用**未取整的原值**参与判定与排序，且带 **0.5% 容差**：≥298.5ppi 即算达标  
（299.75 不报、297 照报）。显示时保留 **1 位小数**（299.6 就显示 299.6，整数仍显示整数），  
避免"写着 300 却被判偏低"的错觉。  
**未完成**：扫描配额被截断，或有图读不出 ppi（文件缺失 / 格式异常 / 缩放矩阵不可用）时报 `未完成`，  
不会落进绿色「全部嵌入」。

> **为什么读不出的图要单独计**：旧版把读不到 ppi 的图**静默丢弃** —— 总数里没有它、  
> 达标里也没有它，面板照样显示"全部达标"。现在它计入总数并单列"无法判定"，  
> 让"没查到"和"查过没问题"在面板上是两件事。

### 卡 ⑤ 油墨 · 描边

卡名带「描边」后缀，因为这张卡同时管三类事：油墨总量、色版深浅、描边线宽。按类型分块，固定顺序：

| 分块 | 判定 |
| -- | -- |
| 油墨总量 > 300 | 红 —— C+M+Y+K 超过 300 的对象 |
| 油墨总量 220~300 | 黄 |
| 色版 < 5% | 黄 —— CMYK 某分量处于 1 与 5 之间（0 表示该色版不用，不算太浅；过浅分量单独标白） |
| 描边 < 0.1mm | 黄 —— 相同宽度合并显示，如 `0.09mm ×3` |

每条样本前标 `[文字]` / `[图形]`；末尾灰字汇总正常数与 RGB / 专色 / 混合色 / 渐变图案。

**徽标按处理必要性排候选**：`超标 N 处`(红) > `偏重 N 处` > `描边细 N 处` > `色版浅 N 处`（均黄），  
主徽标取第一位、次徽标取第二位，**每颗都带自己的类别名**。四类都没有时显示 `无异常`。

> v11.66 之前这条是**互斥链**：有超标就只报「超标 N 处」，把偏重 / 描边细 / 色版浅 三类**加成一个数**  
> 报「注意 N 处」—— 既看不出是哪一类，超标时偏重还会被整段盖掉。

> **RGB / 专色 / 混合色不进徽标**：它们是「文档里有什么」的信息，不是能下手处理的问题，  
> 只出现在末尾的灰色汇总行里。

### 卡 ⑥ 叠印（两版可切）

同一批扫描数据有**两套展示与操作方式**，切换只换显示、不重扫：

| 版本 | 卡头标题 | 看什么 / 能做什么 |
| -- | -- | -- |
| 全清理（默认） | 叠印 · 全清理 | 一条总数线；「一键清除叠印」—— 关掉文档里全部叠印 |
| 分级版 | 叠印 · 分级版 | 四分类；三条规则勾选 + 「执行勾选项」 |

**切换位置**：设置弹层里「叠印」那一行的卡名后面（胶囊页签，白底黑字为当前选中）。  
选择会记住（`pf_ovpMode`），默认「全清理」。卡头标题带版本后缀，一眼能看出当前是哪个。

#### 全清理版

| 项目 | 说明 |
| -- | -- |
| 汇总行 | `共 N 处叠印 · 文字 N · 图形 N · 锁定 N · 白色 N`（后两段仅在 N>0 时出现），下面按量列样本，最多 5 处（同值合并为 `×N`） |
| 徽标 | 有叠印红色 `叠印 N`（截断时 `叠印 N+`）；有白色叠印再拼一段 ` · 白叠印 N` |
| 一键清除 | **有叠印时**卡片底部才出现「解锁全部」复选框与「一键清除叠印」按钮 |

**「纸白」的判定**：CMYK 四分量之和为 0，或 RGB 为 `255,255,255`。  
**专色、灰度、渐变、图案一律不算** —— 它们在印上的表现和「白」是两回事，宁可漏报也不误报。

> **为什么白色叠印要标出来**：白色油墨叠印后**不再遮挡下层**，印出来会花，属明确事故；  
> 而其它叠印（例如「黑字压彩底」）是刻意的常规做法，不一定代表出错，请结合稿件判断。

**一键清除叠印**：关闭文档中**全部**叠印（文字与图形、填充与描边都算），执行前弹确认框；  
**锁定 / 隐藏对象默认跳过**，其显示与锁定状态**一律不改动**，完成后如实回报  
「已清除叠印 N 处，跳过 M 处（锁定/隐藏，状态未改动）」。按钮前的**「解锁全部」**复选框  
（默认不勾、选择会记住）勾上后会**先解除图层与对象锁定**（Ctrl+2 / 锁定组）再清除，  
回报多一句「解除锁定 N 处」；**隐藏对象任何情况下都不碰** —— 要查隐藏内容，先在 AI 里显示出来。

#### 分级版

按处理必要性分四类：

| 分类 | 含义 |
| -- | -- |
| 单黑叠印（正常） | C0 M0 Y0 K100 —— 压印后不再镂空，避免套印露白 |
| 专色叠印（正常） | 专色 / 渐变 / 图案上的叠印 |
| 需处理叠印 | 纯白叠印（印出来会花）+ 彩色叠印（其余 CMYK / RGB 叠印） |

> **两版对"白"的松紧不同**：全清理版用**精确白**（CMYK 四分量全 0 / RGB 255,255,255），  
> 与它「关掉全部叠印」的用途一致；分级版用 **`whiteClass`** —— CMYK 原值和 **< 1** 也算白  
> （例：`C1 M0 Y0 K0` 这种肉眼看着白、印上去同样会花的）。分级版要把"该清的"挑出来，  
> 宁可多挑一点。同一个对象在两版里可能一版标白、一版标彩色，这是**刻意的**，不是 bug。

徽标写成 `需处理 N · 正常 N`；需要处理的那些才会带出勾选与按钮：

- **清除需处理叠印**（默认勾）：清除纯白 + 彩色叠印对象的填充与描边叠印
- **单黑加叠印**（默认不勾）：反过来，为单黑对象**新增**叠印
- **解锁全部**（默认不勾）：执行前先解锁图层、对象级锁定与锁定组

三个勾选记在 `pf_chkClearWhite` / `pf_chkAddK100` / `pf_chkOvpUnlock`，按「执行勾选项」运行。

> 两版的「解锁全部」是**同一个状态**，在哪一版勾都会同步。

汇总行末的 **`锁定 N`** 段：锁定对象的叠印**照常计入**总数（锁定 ≠ 隐藏，检查照收），  
只是默认不清除 —— 悬停可见「勾选「解锁全部」可一并清除」；没有锁定叠印时该段不出现。  
卡内灰字「隐藏对象与图层不参与叠印检查」即指本卡数字**只来自可见对象**。

> 读取口径：图形走对象级 `fillOverprint` / `strokeOverprint`，文字走**字符级**  
> `characterAttributes.overprintFill` / `overprintStroke`。清除动作走同一批属性。

### 卡 ⑦ 清理

对应 Illustrator 自带的「对象 > 路径 > 清理」，三类**看不见但占位置**的对象：

| 项 | 判定 | 来源举例 |
| -- | -- | -- |
| 游离点 | 只有一个锚点、没有任何路径段的路径 | 钢笔点一下没拖、路径删到只剩一个点、PDF 粘贴残留 |
| 未上色对象 | 填充与描边**都为「无」**的路径或复合路径（组 / 图层 / 文本帧不算） | 画了没上色、导入 PDF 带过来的空形状 |
| 空文本路径 | 内容为空，或全是空格 / 制表 / 换行（全角空格也算） | 点了文字工具没输入就切走、删光字但文本框还留着 |

**两类「看着像垃圾、其实有用途」的路径会被自动跳过**：路径文字的基底路径、剪切蒙版的蒙版路径  
（以及剪切组内的所有图形）。它们同样是无填充无描边，但删了会出人命。

| 项目 | 说明 |
| -- | -- |
| 计数 | 三类各报一个数，一行报全；空文本里含纯空格的再单列一行「空文本中纯空格 N 个」 |
| 徽标 | `可清理 N 个`（红）/ `未检查`（黄）/ `无需清理`（绿），卡片左边框同色 |
| 提示 | 命中对象里若含隐藏 / 锁定的，会显示「其中隐藏 N 个、锁定 M 个，一并清理」 |
| 勾选 | 卡内三个勾选框决定「一键清理」清哪几类（默认全勾），勾选状态单独记住 |
| 一键清理 | **清理整个文档**，含隐藏与锁定的对象。隐藏对象直接删、不动可见性；锁定对象先临时解锁，**删失败会把锁原样还回去** |

> **出厂默认开启**。辅助线不算游离点、也不会被删。  
> **路径文字的基底路径受保护**：它本身是「无填充 + 无描边」的路径，但删了文字就没了 —— 判定时跳过。  
> **剪切蒙版受保护**：蒙版路径本身也是「无填充 + 无描边」，且蒙版组内的图形一律不动 ——  
> 这两类都不会被清掉，蒙版不会散。

### 卡 ⑧ 色板

| 项目 | 说明 |
| -- | -- |
| 统计 | 色板 / 渐变 / 图案各报「总数 · 在用 · 未使用」；颜色组只报数量 |
| 判定 | 含隐藏与锁定对象、组与复合路径、已放置的符号、文字字符色与整帧色；「未使用」= 没有任何对象引用它 |
| 徽标 | `未使用 N 个`（红）/ `未检查`（黄）/ `无未使用`（绿）/ `统计失败`（黄） |
| 清理 | 未使用总数 > 0 时出现「删除未使用的色板」按钮，可一次删掉未使用的色板 / 渐变 / 图案 |
| 颜色组 | **一律不删** —— AI 读不到组内成员，删组可能连带删掉色板 |
| 保守闸 | 任何一处颜色**读不出来**（遍历深度超限、组件读失败、文字区间取色失败、色值分量缺失），本轮结论即标 `统计失败`，两个删除入口**直接拒绝执行**并说明原因；单个色板解析失败则按"在用"处理 |

> **为什么宁可不删**：误删色板是**不可逆**的（对象当场改色，撤销也未必能还原链接关系）。  
> 所以这里的取舍一律偏向"留着"：读不到 = 当在用，采不全 = 不删，只把"没查全"如实告诉你。

> **出厂默认关闭**：色板卡 `CARD_CK` 出厂为 `false`，要在「设置」里勾上才会检查（也是「重置默认」的结果）。

## 设置

顶栏「开始检查」左侧的齿轮打开设置，分两块：

| 块 | 内容 |
| -- | -- |
| 卡片开关 / 顺序 | 勾掉哪张卡，本轮就完全不检查它（明显提速）。每行右侧的抓手**按住上下拖**换位，只影响显示顺序、不影响检查内容。⑧ 色板卡出厂默认关；**「叠印」那一行还挂着 `全清理 / 分级版` 页签**（见卡⑥） |
| 判定阈值 | 共 7 项，按默认卡片顺序排：出血（卡①）→ 极小字号（卡③）→ 分辨率（卡④）→ 油墨偏重 / 油墨超标 / 色版低于 / 描边细于（卡⑤） |

底部三颗按钮：**确认**（保存改动）、**重置默认**、**关闭**（放弃改动）。

**落盘规则（v10.37 起为整体草稿式）**：卡片开关、卡片顺序、叠印版本、判定阈值这**四项都不立即生效** ——  
点「确认」才一起写盘；点「关闭」（或按 ESC、或点灰底）**整体回滚**到打开设置那一刻的状态。  
「重置默认」把开关 / 顺序 / 阈值恢复默认（**不含**叠印版本），但也只是改草稿，仍要点「确认」才生效。

改完都要**再点一次「开始检查」**才重算（在设置里改完不会自动重跑）。

存的键：`pf_cards2`（开关）/ `pf_order2`（顺序）/ `pf_ovpMode`（叠印版本）/ `pf_th`（只存你改过的阈值项）。

> `pf_cards2` / `pf_order2` 带 `2` 后缀，是因为 v11.63 把九张卡合并成八张 —— 新旧存档**都是 8 位长度**，  
> 同一个键无法区分，只能换名。老存档会自动迁移：开关按「两张合并卡任一开则合并卡也开」，  
> 顺序则把被删掉的那张整条摘掉、后面的卡号依次前移、缺的补到末尾。迁移只做一次，之后读写的都是新键。

> 本 README 里出现的 300ppi、3mm、0.1mm、6pt、220 与 300、最多 5 条、3000 个，  
> 全部是**默认值** —— 前 7 项都能在设置里改，隐藏文字那 500 帧属诊断性质不开放。  
> 默认值只在宿主脚本里维护一份（`PF_TH_DEF`），面板不留副本，所以改了阈值，  
> 判定和所有卡片文案会一起跟着变。

## 安装（Windows）

**环境要求**：Windows；Illustrator **23（CC 2019）及以上**。清单里写的是 17.0，但扩展同时要求  
CEP 9（CSXS 9），实际下限约为 AI 23 —— 更早版本装上了也未必出现在菜单里。

1. **关闭 Illustrator**
2. **双击 `windows一键安装.bat`**
3. **重启 Illustrator** → 菜单 `窗口 → 扩展功能 → 印前检查-雪糕`

**以后要更新**：直接**再双击一次 `windows一键安装.bat`** 就行 —— 它会先清掉旧的  
`CSXS / css / js / jsx / images` 五个子目录再整个拷回来，所以改过名、删过的文件不会残留  
（注册表开关是幂等的，重写没有副作用）。**卸载**双击 `windows一键卸载.bat`。两者改完都要重启 Illustrator。

> 脚本已做幂等处理，所以「安装」和「更新」是同一个动作，不必区分「第一次装」还是「装过了要升级」。

> **仓库镜像里没有 `images/` 目录**，所以脚本对它是容错的：目录不存在时只打一行 `NOTE` 继续，  
> 不判失败。图标缺了不影响面板功能，只是菜单里显示默认图标。

## 安装（macOS）

**环境要求**：macOS；Illustrator 23（CC 2019）及以上。  
⚠ macOS 版脚本**未经真机验证**，遇到问题请提 Issue。

1. 下载并解压（不要在压缩包里直接双击脚本）
2. **终端**里进入解压后的文件夹，执行：`bash mac一键安装.command`  
   （也可双击 `mac一键安装.command`；若系统拦截，到「系统设置 → 隐私与安全性」点「仍要打开」）
3. **重启 Illustrator** → 菜单 `窗口 → 扩展功能 → 印前检查-雪糕`

脚本做三件事：复制 `CSXS / css / js / jsx / images` 与 `index.html` 到  
`~/Library/Application Support/Adobe/CEP/extensions/yinqianjiancha`、  
写入 CEP 调试开关（`defaults write com.adobe.CSXS.9~16 PlayerDebugMode 1`）、清偏好缓存（`killall cfprefsd`）。  
再跑一次即更新，与 Windows 同理。**卸载**：删除上面那个文件夹即可（访达或终端）。

> 已知未验证点：缺失字体的判定判据在 Windows 真机标定。mac 的字体表若表现不同，缺失字体一项  
> 可能误报/漏报，其余卡不受影响。发现问题请附截图提 Issue。

### 手动安装

`windows一键安装.bat` 没装上时，手动三步：

1. 把整个文件夹复制到 `%APPDATA%\Adobe\CEP\extensions\yinqianjiancha`  
   （`%APPDATA%` 即 `C:\Users\<用户名>\AppData\Roaming`，粘进资源管理器地址栏可直接打开）
2. 重启 Illustrator，看 `窗口 → 扩展功能` 里有没有「印前检查-雪糕」。**有就到此为止**。
3. 还是没有时，才需要打开未签名扩展的调试开关 —— 在 **cmd 窗口**粘这一行，执行完再重启一次 Illustrator：
   ```
   for %V in (9 10 11 12 13 14 15 16) do reg add "HKCU\Software\Adobe\CSXS.%V" /v PlayerDebugMode /t REG_SZ /d 1 /f
   ```

## 已知限制

**判定口径**（看结果时请按这些口径理解）

- Illustrator 脚本接口**读不到**文档「出血」的设置值，面板里的出血是**实测值**  
  （对象到画板边的实际距离，容差 0.05mm）。
- 检查只统计**可见对象**（隐藏内容中的文字、图片会单列，不混进主计数）。  
  **叠印是例外：隐藏对象与图层完全不参与叠印检查**（卡⑥ 内有灰字标注）—— 隐藏内容要读到得  
  先"显示"，而检查是只读的、不改文档状态。
- 图形对象的叠印属性（`PathItem.fillOverprint` / `strokeOverprint`）**尚未在真机验证**：  
  若属性名不成立，图形侧的叠印会**静默漏报**（不会崩溃、也不会误报），「一键清除叠印」  
  同样够不到图形侧。文字侧走字符级 `characterAttributes.overprintFill` / `overprintStroke`，  
  已在 AI 28.0.0 验证可读。
- 叠印一律标红，**包括「黑字压彩底」这类刻意的常规做法**，所以有叠印不一定代表出错  
  —— 想按处理必要性分开看，切到卡⑥ 的「分级版」。

**动作类**（各按钮的副作用）

- **一键转曲**不可撤销，操作前建议先存盘。
- **一键嵌入**不可撤销：PDF / AI / EPS 等矢量链接与位图一样走 Illustrator 原生「嵌入」  
  （v9.9 起不再栅格化），效果与手动嵌入一致；具体结果跟随那次嵌入用的导入选项。
- **一键清除叠印 / 执行勾选项**只改动叠印属性，**不改动图层与对象的显示状态**；锁定或隐藏的对象  
  默认跳过并如实报数。勾选「解锁全部」后会**先解除锁定**（图层锁定、Ctrl+2 对象锁定、锁定组）再执行  
  —— 这是本扩展里除「一键转曲」外第二个会改动图层 / 对象状态的按钮；**隐藏状态任何情况下都不动**。  
  为稳妥起见，操作前也建议先存盘。
- 运行时会**临时**把隐藏内容显示出来以满足「显示全部」，用完**当次调用内复原可见性**  
  （对象级隐藏与隐藏图层都还原，不会留下"全显示"的文档）。  
  而**「解锁全部」是显式选择，解锁保持生效** —— 完成后如实回报「解除锁定 N 处」，不代为回锁。
- **一键清理**（卡⑦）是**唯一会删掉隐藏内容的按钮**：按当前口径，隐藏与锁定的对象也一并清理。  
  隐藏对象直接删除、不改它的可见性；锁定对象先**临时解锁**，删失败会把锁**原样还回去**  
  （不会出现"没删掉还把你的锁解了"）。这一条与其它卡片「隐藏不碰」的口径不同，是刻意为之，  
  执行前请确认；辅助线不在清理范围内。
- 卡⑦「清理」**不处理符号定义源内部**的对象 —— 那里的删除会波及该符号的所有实例，属另一个语义；  
  与 Illustrator 自带清理的范围一致。

**其它**

- 本扩展**未签名**。`windows一键安装.bat` 会写入 `HKCU\Software\Adobe\CSXS.*\PlayerDebugMode`，  
  这是 CEP 加载未签名扩展的**必要条件**，不是漏洞；不接受的话请不要安装。

## 目录结构

```
yinqianjiancha/
├─ index.html             面板界面
├─ css/style.css          样式
├─ js/main.js             面板前端逻辑（渲染 / 交互）
├─ jsx/preflight.jsx      宿主脚本（在 Illustrator 内运行扫描与一键操作）
├─ CSXS/manifest.xml      CEP 扩展清单
├─ images/icon.png        扩展菜单图标（manifest 的 <Icons> 引用，透明底 PNG）
├─ windows一键安装.bat    安装 / 更新（覆盖面板文件，可重复执行）
├─ mac一键安装.command    macOS 安装 / 更新（同上，未经真机验证）
├─ windows一键卸载.bat    卸载
├─ README.md              本文件
├─ 更新日志.txt           完整变更日志
├─ LICENSE                MIT 许可
└─ .gitattributes         换行符规范（.bat 强制 CRLF，其余 LF）
```

> `.gitattributes` 里 `.bat` 用的是 `-text`（**不做换行转换**），并且仓库里存的就是 CRLF、文件内零非 ASCII 字符。  
> 原因是网页「Download ZIP」不会应用 `eol` 转换，而下发后 cmd 会按系统代码页（中文 Windows = GBK）读批处理，  
> UTF-8 中文注释会被解码成乱码、把解析器对引号的判断带偏。这两个条件必须同时成立，改 `.bat` 时别破坏它们。
