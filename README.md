# 印前检查-雪糕

当前版本 **v10.9** · 完整变更日志见 [更新日志.txt](更新日志.txt) · 许可 [MIT](LICENSE)

在 Illustrator 里做印前自检的面板扩展：七张检查卡覆盖出血 / 隐藏内容 / 字体 / 图片 / 油墨 / 叠印，
配**一键转曲**、**一键嵌入**、**一键清除叠印**三个动作按钮。

---

## 功能（七张检查卡）

七张卡**始终全部渲染**：没有问题也会显示「无」，方便确认检查确实跑过。徽标颜色就是严重度：
绿 = 正常，黄 = 注意，红 = 问题；并列徽标单独表达另一类问题，不并入主徽标计数。

| 卡片 | 检查内容 | 徽标（主 / 并列） |
| --- | --- | --- |
| ① 画板 · 出血 · 色彩 | 画板尺寸、逐画板实测出血、色彩模式 | `CMYK` / `RGB`；并列 `出血不足` |
| ② 隐藏图层 · 对象 | 隐藏图层与隐藏对象 | `N 个` / `无` |
| ③ 字体 · 转曲 | 未转曲文本框、字体清单、缺失字体、极小字号 | `未转曲 N 个` / `已转曲`；并列 `缺字体 N`、`小字号 N` |
| ④ 图片嵌入 | 嵌入 / 链接图片数量、未嵌入清单 | `缺失 N 张` / `有链接图` / `全部嵌入` |
| ⑤ 图片分辨率 | 低于 300ppi 的图片 | `有 N 张偏低` / `全部达标` |
| ⑥ 油墨 · 描边粗细 | 油墨总量、描边宽度 | `超标 N 处` / `注意 N 处` / `通过` |
| ⑦ 叠印 | 处于叠印状态的对象（文字与图形） | `叠印 N 处` / `无叠印`；并列 `白叠印 N 处` |

**数量上限**：清单类最多列 5 条，超出时在标题行右端提示「仅列出前 5 处 / 5 张 / 5 个」；
扫描配额为 3000 个对象。两者是两件事——前者管「显示几条」，后者管「扫多少个」；
**命中配额意味着后面的对象没被检查**，请留意。

### 卡 ① 画板 · 出血 · 色彩

| 项目 | 说明 |
| --- | --- |
| 画板清单 | 逐个画板列出名称与尺寸（`宽 × 高 mm`），当前画板标「(当前)」 |
| 出血 | **逐画板实测**四条边（对象到画板边的实际距离，容差 0.05mm）；不足 3mm 的画板会被列出，并标明**具体是哪条边**不足，如「上 0mm、下 0mm、右 2.9mm」 |
| 色彩模式 | 常驻一行。CMYK 显示白字；RGB 显示红字并提示「请转 CMYK（文件 → 文档颜色模式）」 |

出血四边全判：未贴到边的方向按 0mm 计，空画板四边都按 0mm 报；全部达标时显示  
「出血全部 ≥ 3mm，达标。」出血不足时，除主徽标外**追加**一个黄徽标「出血不足」。

### 卡 ② 隐藏图层 · 对象

| 项目 | 说明 |
| --- | --- |
| 统计 | 分别统计**隐藏图层**与**隐藏对象**，汇总为一行「隐藏图层 N 个 · 隐藏对象 N 个」 |
| 清单 | 列出隐藏图层的名称（最多前 5 个）；没有隐藏内容时显示「无 隐藏图层 / 隐藏对象。」 |

### 卡 ③ 字体 · 转曲

| 项目 | 说明 |
| --- | --- |
| 未转曲文本框 | 列出总数与文档中用到的字体名（最多 8 种，超出折叠为「…等 N 种」；名字过长会单行截断，悬停可看全名） |
| 缺失字体 | 命中时列出具体字体名，并追加一个红徽标「缺字体 N」；判据见下 |
| 极小字号 | `N 处字号小于 6pt` 并列出样本（`文字 — N pt`）；**计数与徽标一律标红**（v10.2 起只有这一档，原先 < 5pt 的重度分级已去掉） |
| 隐藏文字 | 树遍历只扫可见对象，隐藏文字单独统计，提示「另有 N 个隐藏文字未转曲，勾选「显示全部」可一并转曲。」（配额：前 500 个） |

> **看徽标别误解**：卡③ 的主徽标是**可见 + 隐藏文字合并计数**——只看徽标会以为隐藏文字也转了曲，以卡内那行提示为准。

**缺失字体的判定**同时用三条判据：

1. 不在系统字体表中；
2. 系统字体表里是**占位条目**（无 style 且 family 为空或等于字体名）；
3. **切分痕迹**——条目的 family / style 恰好是字体名在**首个连字符**处硬切出来的  
   （style = 连字符后段，family = 前段 + 空格 + 后段）。这条是为「名字自带连字符的缺失  
   字体」补的：这类字体旧版会整类漏报。

#### 一键转曲（两个选项）

有未转曲文本框（或隐藏文字）时，卡片底部会出现「一键转曲」按钮，配两个勾选项：

- **显示全部**：转曲前显示隐藏图层，并取消对象级隐藏（Ctrl+3）
- **解锁全部**：转曲前解锁图层，并解除对象级锁定（Ctrl+2）与锁定组

| 勾选组合 | 效果 |
| --- | --- |
| 两项都勾 | 解除全部隐藏与锁定，转曲文档中所有文字 |
| 只勾解锁 | 转曲其中可见的文字；仍隐藏的文字跳过 |
| 只勾显示 | 转曲其中未锁定的文字 |
| 都不勾 | 只转曲本就可见且未锁定的文字，不改动任何状态 |

### 卡 ④ 图片嵌入

| 项目 | 说明 |
| --- | --- |
| 汇总行 | `嵌入图片: N 张 · 链接图片: N 张`，有链接源文件缺失时再补 `· 缺失链接: N 张` |
| 未嵌入清单 | 列文件名（最长 40 字符，悬停看**完整路径**）；源文件不存在的会标记「⚠ 源文件不存在」 |
| 一键嵌入 | 有链接图时出现按钮；确认框标题「确认嵌入」，写明链接图总数（含隐藏对象） |

> **口径提醒**：检查卡与清单**只统计可见对象**；而「一键嵌入」是**文档级操作**，  
> 处理的是文档中**全部**链接图（含隐藏对象），确认框会写明总数。
>
> **嵌入口径（v9.9 起）**：**不再栅格化** —— PDF / AI / EPS 等矢量链接与位图一样走 Illustrator  
> 原生「嵌入」，效果与在 AI 里手动嵌入一致；具体结果（是否保留图层、能否编辑）跟随你上次  
> 嵌入时用的导入选项。操作不可撤销，建议先存盘。

### 卡 ⑤ 图片分辨率

| 项目 | 说明 |
| --- | --- |
| 汇总行 | `共 N 张图片 · 达标 N 张 · <300ppi N 张` |
| 清单 | 文件名（截断，悬停看全名）+ 实际 ppi，最多 5 张；文档没有位图时显示「文档无位图。」 |
| 判定口径 | ppi 用**未取整的原值**参与判定与排序（所以 299.75 不会被当成 300 放行），面板上显示时才取整 |

### 卡 ⑥ 油墨 · 描边粗细

按「问题类型」分块，固定顺序：

| 分块 | 判定 |
| --- | --- |
| 油墨总量 > 300 | 红——C+M+Y+K 超过 300 的对象 |
| 油墨总量 220~300 | 黄 |
| 色版 1~4% | 黄——CMYK 某分量处于 0 与 5 之间（过浅分量单独标白） |
| 描边 < 0.1mm | 黄——相同宽度合并显示，如 `0.09mm ×3` |

每条样本前标 `[文字]` / `[图形]`；末尾灰字汇总正常数与 RGB / 专色 / 混合色 / 渐变图案。

### 卡 ⑦ 叠印

| 项目 | 说明 |
| --- | --- |
| 汇总行 | `共 N 处叠印 · 文字 N · 图形 N · 锁定 N · 白色 N`（后两段仅在 N>0 时出现），下面按量列样本，最多 5 处（同值合并为 `×N`） |
| 主徽标 | 有叠印时红色 `叠印 N 处`，没有时绿色 `无叠印` |
| 白叠印 | 填充或描边为**纸白**时单独计数：汇总行加一段 `白色 N`，并追加红色并列徽标 `白叠印 N 处`（鼠标悬停有危害说明） |
| 范围标注 | 卡内常显灰字说明检查范围；有锁定叠印时汇总行加一段 `锁定 N`（鼠标悬停说明如何一并清除） |
| 一键清除 | **有叠印时**卡片底部才出现「解锁全部」复选框与「一键清除叠印」按钮 |

**「纸白」的判定**：CMYK 四分量之和为 0，或 RGB 为 `255,255,255`。
**专色、灰度、渐变、图案一律不算**——它们在印上的表现和「白」是两回事，宁可漏报也不误报。

> **为什么白色叠印要标出来**：白色油墨叠印后**不再遮挡下层**，印出来会花，属明确事故；
> 而其它叠印（例如「黑字压彩底」）是刻意的常规做法，不一定代表出错，请结合稿件判断。

**一键清除叠印**：关闭文档中**全部**叠印（文字与图形、填充与描边都算），执行前弹确认框；
**锁定 / 隐藏对象默认跳过**，其显示与锁定状态**一律不改动**，完成后如实回报
「已清除叠印 N 处，跳过 M 处（锁定/隐藏，状态未改动）」。按钮前的**「解锁全部」**复选框
（默认不勾、选择会记住）勾上后会**先解除图层与对象锁定**（Ctrl+2 / 锁定组）再清除，
回报多一句「解除锁定 N 处」；**隐藏对象任何情况下都不碰**——要查隐藏内容，先在 AI 里显示出来。

汇总行末的 **`锁定 N`** 段：锁定对象的叠印**照常计入**总数（锁定 ≠ 隐藏，检查照收），
只是默认不清除——悬停可见「勾选「解锁全部」可一并清除」；没有锁定叠印时该段不出现。
卡内灰字「隐藏对象与图层不参与叠印检查」即指本卡数字**只来自可见对象**。

> 读取口径：图形走对象级 `fillOverprint` / `strokeOverprint`，文字走**字符级**
> `characterAttributes.overprintFill` / `overprintStroke`。清除动作走同一批属性。

## 设置

顶栏「开始检查」左侧的齿轮打开设置，分三块：

| 块 | 内容 |
| --- | --- |
| 卡片开关 | 勾掉哪张卡，本轮就完全不检查它（明显提速），该卡显示灰色「已关闭」占位 |
| 卡片顺序 | 每行右侧的抓手**按住上下拖**即可换位，**只影响显示**，不影响检查内容 |
| 判定阈值 | 共 6 项可改，**按默认卡片顺序排**：出血（卡①）→ 极小字号（卡③）→ 分辨率（卡⑤）→ 描边、油墨偏重、油墨超标（卡⑥） |

底部三颗按钮：**确认**（保存改动）、**重置默认**（点下即重置：卡片开关 + 顺序 + 阈值一起回默认）、
**关闭**（放弃尚未确认的改动；按 ESC 或点灰底也是一样）。

开关 / 顺序 / 阈值分别存在 `pf_cards` / `pf_order` / `pf_th` 三个 localStorage 键里。
开关与顺序即时落盘，**阈值要点「确认」才落盘**；三者都要**再点一次「开始检查」才生效**
（在设置里改完不会即时重算）。

> 本 README 里出现的 300ppi、3mm、0.1mm、6pt、220 与 300、最多 5 条、3000 个，
> 全部是**默认值** —— 前 6 项都能在设置里改。这些默认值只在宿主脚本里维护一份，
> 面板不留副本，所以改了阈值，判定和所有卡片文案会一起跟着变。

## 安装（Windows）

**环境要求**：Windows；Illustrator **23（CC 2019）及以上**。清单里写的是 17.0，但扩展同时要求
CEP 9（CSXS 9），实际下限约为 AI 23——更早版本装上了也未必出现在菜单里。
扫描用 AI 自带的 ExtendScript，无需另装运行时。

1. **关闭 Illustrator**
2. **双击 `安装.bat`**
3. **重启 Illustrator** → 菜单 `窗口 → 扩展功能 → 印前检查-雪糕`

**以后要更新**：直接**再双击一次 `安装.bat`** 就行——它会直接覆盖面板文件
（注册表开关是幂等的，重写没有副作用）。**卸载**双击 `卸载.bat`。两者改完都要重启 Illustrator。

> 脚本已做幂等处理：目录只在不存在时创建，文件一律直接覆盖。所以「安装」和「更新」是同一个动作，
> 不必区分「第一次装」还是「装过了要升级」。

## 安装（macOS）

**环境要求**：macOS；Illustrator 23（CC 2019）及以上。⚠ macOS 版脚本**未经真机验证**，遇到问题请提 Issue。

1. 下载并解压（不要在压缩包里直接双击脚本）
2. **终端**里进入解压后的文件夹，执行：`bash mac一键安装.command`
   （也可双击 `mac一键安装.command`；若系统拦截，到「系统设置 → 隐私与安全性」点「仍要打开」）
3. **重启 Illustrator** → 菜单 `窗口 → 扩展功能 → 印前检查-雪糕`

脚本做三件事：复制文件到 `~/Library/Application Support/Adobe/CEP/extensions/yinqianjiancha`、
写入 CEP 调试开关（`defaults write com.adobe.CSXS.9~14 PlayerDebugMode 1`）、清偏好缓存（`killall cfprefsd`）。
再跑一次即更新，与 Windows 同理。**卸载**：删除上面那个文件夹即可（访达或终端）。

> 已知未验证点：缺失字体的判定判据在 Windows 真机标定，mac 的字体表若表现不同，缺失字体一项
> 可能误报/漏报，其余六卡不受影响。发现问题请附截图提 Issue。

### 手动安装

`安装.bat` 没装上时，手动三步：

1. 把整个文件夹复制到 `%APPDATA%\Adobe\CEP\extensions\yinqianjiancha`（`%APPDATA%` 即 `C:\Users\<用户名>\AppData\Roaming`，粘进资源管理器地址栏可直接打开）
2. 重启 Illustrator，看 `窗口 → 扩展功能` 里有没有「印前检查-雪糕」。**有就到此为止**。
3. 还是没有时，才需要打开未签名扩展的调试开关——在 **cmd 窗口**粘这一行，执行完再重启一次 Illustrator：
   ```
   for %V in (9 10 11 12 13 14) do reg add "HKCU\Software\Adobe\CSXS.%V" /v PlayerDebugMode /t REG_SZ /d 1 /f
   ```

## 已知限制

**判定口径**（看结果时请按这些口径理解）

- Illustrator 脚本接口**读不到**文档「出血」的设置值，面板里的出血是**实测值**  
  （对象到画板边的实际距离，容差 0.05mm）。
- 检查只统计**可见对象**（隐藏内容中的文字、图片会单列，不混进主计数）。
  **叠印是例外：隐藏对象与图层完全不参与叠印检查**（卡 ⑦ 内有灰字标注）——隐藏内容要读到得
  先"显示"，而检查是只读的、不改文档状态。
- 图形对象的叠印属性（`PathItem.fillOverprint` / `strokeOverprint`）**尚未在真机验证**：  
  若属性名不成立，图形侧的叠印会**静默漏报**（不会崩溃、也不会误报），「一键清除叠印」  
  同样够不到图形侧。文字侧走字符级 `characterAttributes.overprintFill` / `overprintStroke`，  
  已在 AI 28.0.0 验证可读。
- 叠印一律标红，**包括「黑字压彩底」这类刻意的常规做法**，所以有叠印不一定代表出错。

**动作类**（各按钮的副作用）

- **一键转曲**不可撤销，操作前建议先存盘。
- 一键转曲**够不到符号（Symbol）内部的文字**：检查会把它计入「未转曲」，但转曲动作  
  只遍历文档画布上的文本。若文档确实用到符号文字，报告里会提示符号个数。
- **一键嵌入**不可撤销：PDF / AI / EPS 等矢量链接与位图一样走 Illustrator 原生「嵌入」
  （v9.9 起不再栅格化），效果与手动嵌入一致；具体结果跟随那次嵌入用的导入选项。
- **一键清除叠印**只关闭叠印属性，**不改动图层与对象的显示状态**；锁定或隐藏的对象默认跳过
  并如实报数。勾选「解锁全部」后会**先解除锁定**（图层锁定、Ctrl+2 对象锁定、锁定组）再清除
  ——这是本扩展里除「一键转曲」外第二个会改动图层 / 对象状态的按钮；**隐藏状态任何情况下都不动**。
  为稳妥起见，操作前也建议先存盘。

**其它**

- 本扩展**未签名**。`安装.bat` 会写入 `HKCU\Software\Adobe\CSXS.*\PlayerDebugMode`，  
  这是 CEP 加载未签名扩展的**必要条件**，不是漏洞；不接受的话请不要安装。
